# 分数计算说明

基本面总分满分 100。先计算 6 个模块各自的 0-100 模块分，再按权重加权。

## 总分公式

总分 =
团队分 x 0.25
+ 融资分 x 0.20
+ 投资方 x 0.15
+ 社媒分 x 0.20
+ 链生态 x 0.05
+ TGE 前交易所 x 0.15

例：团队 85、融资 96、投资方 100、社媒 87、链生态 95、TGE 前交易所 95，则总分约为：

85 x 0.25 + 96 x 0.20 + 100 x 0.15 + 87 x 0.20 + 95 x 0.05 + 95 x 0.15 = 91.55

## 团队分 25%

  • 团队分使用抓取到的 team raw score 作为基础分，范围是 0-100。
  • 如果团队背景被识别为 pure_chinese / chinese / cn，最终团队分会乘以 0.30，等于扣掉 70%。
  • 非纯中文团队不做这个 0.30 折扣，直接使用 0-100 的基础团队分。
  • 展示文案里的实名成员数、地区识别人数、国际化/中文团队判断，是解释 team raw score 的主要证据。

## 融资分 20%

当前优先使用 RootData 赛道融资排名公式：

融资分 = min(赛道排名分 + 金额加成, 100) x 融资时间系数
  • 赛道排名分锚点：第 1 名 = 90，第 10 名 = 82，第 30 名 = 72，第 100 名 = 50，第 300 名 = 25；300 名以后 = 10。锚点之间线性插值。
  • 金额加成范围是 0-10。同赛道融资金额分位越高，加成越接近 10；没有金额或没有同赛道金额样本时，加成 = 0。
  • 融资时间系数：0-365 天 = x1.00，不扣分。
  • 融资时间系数：366-730 天 = x0.85，等于扣 15%。
  • 融资时间系数：731-1095 天 = x0.65，等于扣 35%。
  • 融资时间系数：超过 1095 天 = x0.45，等于扣 55%。

如果没有赛道排名，才会退回旧公式：融资金额最高按 500,000,000 美元折算 50 分，融资时间一年内最高 50 分；缺少金额或时间时融资分 = 0。

## 投资方 15%

  • 命中 2 个及以上顶级机构 = 100。
  • 命中 1 个顶级机构 + 至少 1 个强机构 = 95。
  • 命中 1 个顶级机构 = 90。
  • 命中 2 个及以上强机构 = 85。
  • 命中 1 个强机构 = 70。
  • 没有顶级/强机构，但有 3 个及以上具名投资方 = 55。
  • 只有 1-2 个普通具名投资方 = 45；没有投资方信息 = 0。

顶级机构关键词包括：YZi Labs、Binance Labs、Coinbase Ventures、Founders Fund、a16z、Paradigm、Polychain、Multicoin、Jump Crypto、Dragonfly。强机构关键词包括：Hashed、Spartan、Animoca、Delphi、IOSG、Maven 11、Mirana、Galaxy、OKX Ventures、HashKey。

## 社媒分 20%

  • 社媒分按 X followers 在同赛道 benchmark 里的百分位计算，范围是 0-100。
  • 计算方式是同赛道中有多少项目粉丝数低于当前项目，再换算成百分位。
  • 如果缺少 X followers，社媒分 = 0。
  • 如果同赛道只有 1 个可比样本，且当前项目粉丝数不低于该样本，社媒分 = 100；否则 = 0。

## 链生态 5%

  • Base = 100。
  • Solana = 95。
  • Sui = 90。
  • BNB Chain / BSC = 85。
  • Ethereum / zkSync / Starknet / 零知识相关 = 80。
  • Arbitrum / Optimism / Polygon / Mantle / Linea / Scroll / Blast = 75。
  • Avalanche / Aptos / Sei / Near / Cosmos / TON = 65。
  • 有链信息但未命中以上规则 = 35；没有链信息 = 0。
  • 多链项目取最高命中的链生态分。

## TGE 前交易所 15%

这一项主要来自各交易所公告、交易所 listing 页面和本地 exchange-listings 数据库，判断项目是否有高质量上线或预上线信号。BN Alpha 不计入这一项。

  • 只有公告发布时间不晚于 TGE 日期的信号才计入这一项；没有公告时间时才用交易开始时间兜底。TGE 后才公告或上线的交易所只展示在上线情况里，不给 TGE 前交易所加分。
  • Coinbase，或 Upbit / Bithumb 韩元现货信号 = 95。
  • BN 现货 = 85。
  • OKX / Bybit / Kraken 任一命中 = 78。
  • BN 合约 / Binance Futures / Binance Perpetual = 75。
  • 普通主流现货交易所只统计 Gate、Bitget、KuCoin、MEXC：1 家 = 55，2 家 = 50，3-4 家 = 40，5 家及以上 = 30。
  • 没有可信交易所公告或 listing 信号 = 10。
